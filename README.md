# WebCube — pCubes browser port

This repository hosts the browser-port work for the Lazarus/Free Pascal pCubes puzzle simulator.

## Deployment status

Vercel can deploy the static browser shell from `pcubes_pascal_web/web`. The compiled `pcubes_web.js` bundle is generated by Pas2JS and is **not checked in**. Until the Pas2JS build is run in CI or supplied as a build artifact, the deployed page will show a clear missing-runtime status rather than a working puzzle simulator.

## Project status

- The browser UI and Pascal bridge scaffold exist in the port workspace.
- The original `TPuzzle` model is referenced by the bridge.
- Puzzle XML loading and 3D rendering are not complete.
- A successful end-to-end browser build has not yet been verified.
- Backups are kept alongside modified Pascal units (`.bak`) and in separate ZIP snapshots during development.

## Local build

Install Pas2JS 3.2.0 and make sure its `bin` and `packages` directories are available. On Windows run `pcubes_pascal_web/build/build.bat`; on Linux/macOS run `pcubes_pascal_web/build/build.sh`.

## Vercel

The root `vercel.json` publishes the static shell. It does not compile Pascal. The next deployment step is to add a reproducible Pas2JS compiler setup to CI, then configure Vercel to deploy the generated bundle.
